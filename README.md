# ⚡ Neon Pulse: Beat Dash

Атмосферный киберпанк ритм-раннер с механикой смены полярности на движке **Phaser 3 / Vite / TypeScript**.

Проект разработан в рамках курса **«Проектирование и разработка игровых приложений»**.

---

## 🎮 Описание игры

Вы управляете сгустком квантовой энергии («Neon Pulse»), мчащимся по 3 неоновым рельсам. Ваша задача — лавировать между полосами, переключать полярность (Голубой ↔ Розовый), собирать сферы ритма своего цвета и уклоняться от смертоносных лазерных шипов.

### 5 ключевых ответов геймдизайна:
1. **Кто игрок:** Квантовый энергетический импульс.
2. **Что делает большую часть времени:** Перемещается между 3 полосами и переключает полярность.
3. **Зачем:** Набирать максимальный счет, разгоняя комбо-множитель под ритмичный бит.
4. **Что мешает:** Сферы противоположного цвета и нейтральные лазерные шипы.
5. **Когда игра заканчивается:** Когда исчерпана энергия щита (3 жизни).

## 🕹️ Управление

Игра поддерживает **двойную схему управления** (ПК и мобильные устройства/планшеты):

| Действие | Клавиатура (ПК) | Сенсорный экран / Мышь |
|---|---|---|
| **Смена полосы** | `W` / `S` или `↑` / `↓` | Клик/тап по нужной полосе или кнопки `▲`/`▼` |
| **Смена полярности** | `Space` (Пробел) / `F` / `E` | Кнопка `⚡ ЦВЕТ` в правом нижнем углу |
| **Рестарт** | `R` или `Space` | Кнопка на экране Game Over |
| **Звук** | — | Переключатель `🔊 SOUND` в правом верхнем углу |
| **Свой трек** | — | Кнопка `📁 ЗАГРУЗИТЬ ТРЕК` или Drag & Drop любого MP3/WAV в окно |

## ✨ Особенности и «Juice»

- **Загрузка своей музыки:** Поддержка любых файлов `.mp3`, `.wav`, `.ogg` через Web Audio API с мгновенным воспроизведением.
- **Аудио-реактивное окружение:** 
  - Неоновый 24-полосный эквалайзер спектра частот внизу экрана;
  - Пульсация ауры игрока и свечения полос под силу баса;
  - Звездное поле ускоряется в такт музыке;
  - **Детектор бита (Beat Detector):** при воспроизведении своей музыки ритм-сферы спавнятся синхронно с пиками трека!
- **Процедурный саундтрек по умолчанию:** Если свой трек не выбран, играет процедурный бит (125 BPM) и синтезированные звуки.
- **«Долгие» очки (Hold Beams / Слайдеры):** Протяженные неоновые лучи энергии, по которым нужно сёрфить в правильном цвете на протяжении всей длины, непрерывно собирая очки и получая взрывной бонус `PERFECT HOLD! (+500)` на финише.
- **Анимация полета очков и Punch-эффект:** При сборе очков всплывающие числа устремляются прямо в счетчик `SCORE`, вызывая упругую отдачу (scale bounce 1.4x), вспышку света и сноп неоновых искр.
- **Плотный поток препятствий и ритма:** Оптимизированный интервал появления объектов (620 мс) с гарантированным стабильным темпом даже при загрузке своей спокойной музыки.
- **Кулдаун на аптечки:** Изумрудные ремонтные наниты `+HP` появляются с выверенным кулдауном (14 секунд), спасая при низком здоровье.
- **Динамический шлейф и частицы:** Эффектные неоновые взрывы искр при сборе сфер и след за импульсом.
- **Комбо-система:** Наращивание множителя очков (`x1` → `x2` → `x4` → `x8`).
- **Screen Shake & Feedback:** Тактильная отдача камеры при столкновениях и повреждении щита.
- **Сохранение рекорда:** Лучший результат сохраняется в `localStorage`.

## 🚀 Запуск и сборка

### Требования
- **Node.js** >= 20.19.0
- **npm**

### Установка зависимостей
```bash
npm install
```

### Локальный запуск (Dev-сервер)
```bash
npm run dev
```

### Проверка типов и сборка для production
```bash
npm run typecheck
npm run build
```

Итоговый бандл собирается в папку `dist/`.
